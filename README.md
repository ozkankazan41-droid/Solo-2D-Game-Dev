# Dungeon Survivors

Dungeon Survivors is a 2D roguelite survival game that I've been building
from scratch on my own using GDevelop.

The idea started pretty simple: make a game that I would actually enjoy
playing myself. Over time, it grew into a much bigger project with
different weapons, characters, enemies, abilities and dungeons.

I'm still actively working on it and improving the game piece by piece.

---

## 🎮 About the Game

You enter a dungeon, fight waves of enemies, collect XP and become stronger
as the run goes on.

Every run is about making the right upgrades, surviving longer and finding
a good combination of weapons and abilities.

The game takes inspiration from the survival roguelite genre, while I'm
trying to build my own style and systems around it.

---

## ⚔️ Current Features

- Multiple playable characters
- Multiple weapons
- Weapon upgrades
- Ability and upgrade cards
- Enemy waves
- Boss fights
- XP and level-up system
- Different dungeons
- Chests and items
- Character progression
- Mobile controls
- VFX and combat effects

More content and systems are still being added.

---

## 🛠️ Made With

- GDevelop
- GDevelop AI
- JavaScript
- A lot of trial and error

The entire game is being developed by me.
